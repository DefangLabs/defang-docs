# Deploying from GitHub Actions

Defang makes it easy to deploy your applications directly from your GitHub Actions workflow using the [Defang GitHub Action](https://github.com/DefangLabs/defang-github-action).

There is a dedicated tutorial for deploying to each cloud provider:

* [AWS](https://docs.defang.io/docs/tutorials/deploying-from-github-actions/to-aws.md)
* [Azure](https://docs.defang.io/docs/tutorials/deploying-from-github-actions/to-azure.md)
* [GCP](https://docs.defang.io/docs/tutorials/deploying-from-github-actions/to-gcp.md).
