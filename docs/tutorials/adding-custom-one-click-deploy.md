# Adding 1-Click Deploy to your project

1-Click Deploy links deployed to the Defang Playground, which has been shut down, so new links no longer work. To let others deploy your app, point them to [Getting Started](https://docs.defang.io/docs/intro/getting-started.md), or set up [deploys from GitHub Actions](https://docs.defang.io/docs/tutorials/deploying-from-github-actions/to-aws.md).
