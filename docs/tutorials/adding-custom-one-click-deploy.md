# Adding 1-Click Deploy to your project

1-Click Deploy links deployed to the Defang Playground, which has been shut down, so new links no longer work. To let others deploy your app, point them to [Getting Started](/docs/intro/getting-started), or set up [deploys from GitHub Actions](/docs/tutorials/deploying-from-github-actions/to-aws).
