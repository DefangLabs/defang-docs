# Using 1-Click Deploy

1-Click Deploy deployed samples to the Defang Playground, which has been shut down. To deploy a sample now, follow [Getting Started](https://docs.defang.io/docs/intro/getting-started.md), or set up [deploys from GitHub Actions](https://docs.defang.io/docs/tutorials/deploying-from-github-actions/to-aws.md) to your own cloud account.
