# Defang Station

Defang Station is a persistent cloud workspace for AI coding agents. Your agent
keeps running when you close your laptop, and the work it does stays where you
left it.

:::info
Station is in development. This section is a placeholder so the two products
have a home in the docs. Documentation lands when Station ships.
:::

## How it relates to Defang Deploy

| | What it is for |
|---|---|
| **[Defang Deploy](/docs/intro)** | Getting an app or an agent into production on your own cloud |
| **Defang Station** | Giving an AI coding agent a machine to work on |

Station runs on Defang's cloud. It is open source, so you can also run it on
your own infrastructure. Defang Deploy still deploys into your cloud account.
