# What is Defang Deploy?

[YouTube video player](https://www.youtube.com/embed/afglsBYieuc?si=iKgUX4ejz7AixxqQ)

## Develop Once, Deploy Anywhere.[​](#develop-once-deploy-anywhere "Direct link to Develop Once, Deploy Anywhere.")

Defang Deploy lets you take your app from Docker Compose to a secure and scalable deployment on your favorite cloud in minutes.

Any App, Any Stack, Any Cloud.

### Get Started Quickly[​](#get-started-quickly "Direct link to Get Started Quickly")

The [Defang CLI (command line interface)](https://docs.defang.io/docs/intro/getting-started.md#install-the-defang-cli) includes an AI agent that translates natural language prompts to [generate an outline](https://docs.defang.io/docs/tutorials/generate-new-code-using-ai.md) for your project that you can then refine. Or choose from our [library of over 50 samples](https://defang.io/samples/) covering all major frameworks and technologies.

### Deploy with a Single Command[​](#deploy-with-a-single-command "Direct link to Deploy with a Single Command")

Defang Deploy can automatically build and deploy your project with a single command.

* Once you're ready, you can [deploy](https://docs.defang.io/docs/tutorials/deploy-to-your-cloud.md) a project to your own cloud account - we call this [Defang BYOC (Bring-your-Own-Cloud)](https://docs.defang.io/docs/concepts/defang-byoc.md). We offer support for the following cloud providers:

  <!-- -->

  * [Amazon Web Services (AWS)](https://docs.defang.io/docs/tutorials/deploy-to-aws.md)
  * [Google Cloud Platform (GCP)](https://docs.defang.io/docs/tutorials/deploy-to-gcp.md)
  * [Microsoft Azure](https://docs.defang.io/docs/tutorials/deploy-to-azure.md)

* To support stateful workloads, we've got managed storage options such as [Managed Postgres](https://docs.defang.io/docs/concepts/managed-storage/managed-postgres.md) and [Managed Redis](https://docs.defang.io/docs/concepts/managed-storage/managed-redis.md).

* If you want, you can also [bring your own domain name](https://docs.defang.io/docs/tutorials/use-your-own-domain-name.md) for your deployment.

Defang Deploy takes care of all the heavy lifting such as configuring networking, security, [observability](https://docs.defang.io/docs/concepts/observability.md) and all the other details that usually slow down the average cloud developer. It also allows you to easily [publish updates](https://docs.defang.io/docs/concepts/deployments.md#deploying-updates) to your deployed application with zero downtime.

### Debug[​](#debug "Direct link to Debug")

Once you've deployed, you can use our AI agent to help [debug](https://docs.defang.io/docs/concepts/debug.md) your cloud applications, using your service logs and project files to help you identify and resolve issues.
