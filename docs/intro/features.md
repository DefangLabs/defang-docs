# Defang Deploy Features

Defang Deploy provides a streamlined experience to develop, deploy, and debug your cloud applications. Defang Deploy includes the following features:

### Wide Variety of Use Cases[​](#wide-variety-of-use-cases "Direct link to Wide Variety of Use Cases")

* Support for [various types of applications](https://docs.defang.io/docs/intro/use-cases.md): web services and APIs, mobile app backends, ML services, hosting LLMs, etc...
* Support for your programming [language of choice](https://defang.io/samples): Node.js, Python, Golang, or anything else you can package in a Dockerfile

### AI-Driven Features[​](#ai-driven-features "Direct link to AI-Driven Features")

* Built-in AI agent to go [from natural language prompt to an outline project](https://docs.defang.io/docs/tutorials/generate-new-code-using-ai.md)
* Built-in AI agent to help you [debug your cloud applications](https://docs.defang.io/docs/concepts/debug.md)

### Container Friendly[​](#container-friendly "Direct link to Container Friendly")

* Automated [Dockerfile builds](https://docs.defang.io/docs/concepts/deployments.md)
* Support for [pre-built Docker containers](https://docs.defang.io/docs/tutorials/deploy-container-using-the-cli.md), from public or private image registries
* Ability to express your project configuration using a [Docker Compose YAML](https://docs.defang.io/docs/concepts/compose.md) file

### Effortless Deployment[​](#effortless-deployment "Direct link to Effortless Deployment")

* [One-command deployments](https://docs.defang.io/docs/intro/getting-started.md#install-the-defang-cli)
* Support for [GPUs](https://docs.defang.io/docs/concepts/resources.md) and [managed storage options](https://docs.defang.io/docs/concepts/managed-storage.md)
* Support for Infra-as-Code via the [Defang Pulumi provider](https://docs.defang.io/docs/concepts/pulumi.md)

### Security and Configuration[​](#security-and-configuration "Direct link to Security and Configuration")

* Ability to manage [encrypted configuration values](https://docs.defang.io/docs/concepts/configuration.md)
* Pre-configured environments with built-in [security](https://docs.defang.io/docs/concepts/security.md), [networking](https://docs.defang.io/docs/concepts/networking.md), and [observability](https://docs.defang.io/docs/concepts/observability.md)
