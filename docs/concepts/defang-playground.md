# Defang Playground

The Defang Playground has been shut down, and you can no longer deploy to it. To deploy with Defang Deploy, use your own AWS, Google Cloud or Azure account: see [Getting Started](/docs/intro/getting-started) and [Defang BYOC](./defang-byoc).
