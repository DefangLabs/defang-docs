# Defang Station

**Bring your agent. Run it anywhere.**

Defang Station gives Claude Code or OpenAI Codex an always-on machine, connected to your own Anthropic or OpenAI account. Open it in any browser to check in on the work, steer it, or take over.

info

Station is in development. This section is a placeholder so the products have a home in the docs. Documentation lands when Station ships.

## How it relates to Defang Deploy[​](#how-it-relates-to-defang-deploy "Direct link to How it relates to Defang Deploy")

|                                                           | What it is for                                               |
| --------------------------------------------------------- | ------------------------------------------------------------ |
| **[Defang Deploy](https://docs.defang.io/docs/intro.md)** | Getting an app or an agent into production on your own cloud |
| **Defang Station**                                        | Giving an AI coding agent a machine to work on               |

Station runs on Defang's cloud. Defang Deploy still deploys into your own cloud account, so what your agent builds on Station can ship to dev, staging or production on the provider you choose.

## Running it yourself[​](#running-it-yourself "Direct link to Running it yourself")

Station is built on [Agent Box](https://github.com/defangdevs/agent-box), an open-source (MIT) runtime that you can run on your own infrastructure — on AWS, on bare metal, or as a machine image. Station is the hosted product built around it; the runtime underneath is yours to take.
