# Playground

The Defang Playground has been shut down, and you can no longer deploy to it. Defang Deploy runs your app in your own AWS, Google Cloud or Azure account. See [Getting Started](https://docs.defang.io/docs/intro/getting-started.md), or [migrate an existing project to your own cloud account](https://docs.defang.io/docs/tutorials/deploy-to-your-cloud.md).
