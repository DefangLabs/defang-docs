# Playground

Defang Playground has been discontinued. It was a shared, Defang-hosted environment for trying Defang without a cloud account. You can no longer deploy to it.

Deploy to your own AWS, GCP, Azure, or DigitalOcean account instead. See [Defang Providers](/docs/providers) for what each provider supports and how to set up credentials, or follow [Deploy to your own cloud](/docs/tutorials/deploy-to-your-cloud).
